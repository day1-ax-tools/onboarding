설치 전 확인

Codex 공식 설치 문서 열기

설치

1 Codex CLI 설치

macOS, Linux, WSL에서는 standalone installer를 사용합니다.

Terminalbash
$ curl -fsSL https://chatgpt.com/codex/install.sh | sh
2 설치 확인
Terminalbash
$ codex --version

버전 번호가 출력되면 설치가 완료된 것입니다.

3 Codex 실행 및 로그인
Terminalbash
$ codex

브라우저 로그인 안내가 나오면 ChatGPT 계정 또는 API key 흐름을 따라갑니다.

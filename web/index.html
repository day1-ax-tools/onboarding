처음 시작

먼저 명령어를 입력할 화면을 엽니다. 설치 자체도 앞으로 반복해서 쓰게 될 기본 경험이므로, 온보딩 키트 없이 CLI 설치와 설치 확인을 먼저 진행합니다. 이미 설치되어 있다면 설치 명령을 다시 실행하지 않고 설치 확인부터 시작합니다.

Codex 공식 설치 문서 열기
0 명령어 입력 화면 열기
  1. macOS: Command + Space를 누르고 Terminal을 입력한 뒤 Enter를 누릅니다.
  2. Linux: Ctrl + Alt + T를 누르거나 앱 목록에서 Terminal을 엽니다.
  3. WSL: 시작 메뉴에서 Ubuntu 또는 WSL 앱을 엽니다.

창이 열리면 user@MacBook-Pro ~ % 또는 $ 같은 프롬프트가 보입니다. 그 오른쪽에 아래 명령어를 붙여넣습니다.

  1. PowerShell: 시작 메뉴를 열고 PowerShell을 검색한 뒤 Windows PowerShell을 실행합니다.
  2. 창이 열리면 PS C:\Users\user> 같은 프롬프트가 보입니다.
  3. 그 오른쪽에 아래 설치 명령어를 붙여넣고 Enter를 누릅니다.

Windows에서는 아래 명령을 PowerShell에서 실행하는 것을 기준으로 안내합니다.

CLI 설치

이미 설치한 사용자 Codex가 이미 설치되어 있다면

설치 명령을 다시 실행하지 말고, codex --version으로 현재 터미널에서 실행되는지만 확인하세요.

설치 확인부터 시작 성공하면 온보딩 키트 받기
1 Codex CLI 설치

macOS, Linux, WSL에서는 standalone installer를 사용합니다.

Terminalbash
$ curl -fsSL https://chatgpt.com/codex/install.sh | sh
2 PATH 반영

설치 직후 현재 터미널이 새 PATH를 아직 모를 수 있습니다. 아래 명령을 한 번 실행해서 현재 창에 codex 명령 경로를 반영합니다.

Terminalbash
$ export PATH="$HOME/.local/bin:$PATH"
command -v codex

경로가 출력되면 현재 창에서 명령어를 실행할 준비가 된 것입니다. 아무 경로도 나오지 않으면 설치 출력에 나온 오류를 확인한 뒤 설치 명령을 다시 실행합니다.

3 설치 확인
Terminalbash
$ codex --version

버전 번호가 출력되면 설치와 PATH 반영이 완료된 것입니다. 명령어를 찾을 수 없다고 나오면 2번 PATH 반영 명령을 다시 실행합니다.

온보딩 키트 준비

CLI 명령이 실행 가능한 것을 확인한 뒤, 같은 터미널에서 온보딩 키트를 받습니다. 이 키트는 설치 자체에 필요한 것이 아니라, 이후 지침 파일, skill, 상태 hook, 온보딩 보드를 프로젝트에 설치하기 위한 자료입니다.

4 온보딩 키트 받기

이 명령은 온보딩 키트를 내 컴퓨터에 준비합니다. 완료되면 시작 페이지가 열리거나, 직접 열 수 있는 주소가 표시됩니다.

Terminalbash
$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/day1-ax-tools/onboarding/main/bootstrap/start.sh)"

여기까지가 일반 터미널에서 한 번에 처리할 작업입니다. 이미 로컬 온보딩 키트가 준비되어 있다면 이 단계는 다시 실행하지 않아도 됩니다.

CLI 실행 및 로그인

이제 설치된 CLI를 실행합니다. 여기부터는 일반 터미널 명령을 계속 입력하는 흐름이 아니라, Codex 또는 Claude Code의 첫 실행 화면에서 인증을 마친 뒤 대화형 온보딩으로 넘어갑니다.

5 Codex 실행 및 로그인
Terminalbash
$ codex

브라우저 로그인 안내가 나오면 ChatGPT 계정 또는 API key 흐름을 따라갑니다. 인증이 끝나면 아래 온보딩 문장을 CLI 입력창에 붙여넣습니다.

C Codex CLI

Codex 첫 실행에서는 로그인 방식 선택, 시작 전 안내, 작업 폴더 신뢰 확인이 나올 수 있습니다.

CLI로 넘기기

아래 짧은 시작 문장을 로그인된 CLI에 붙여넣습니다. 세부 절차는 온보딩 키트 안의 지침과 skill이 이어서 처리합니다.

Claude Code에서 권한 요청이 여러 번 나올 수 있습니다. 온보딩 키트 설치, 파일 읽기, 상태 파일 작성, 보드 생성에 필요한 요청입니다. 이 온보딩 단계에서는 요청이 나오면 1. Yes를 선택해서 계속 진행하세요.

지금 AI와 함께 작업하려는 폴더에 온보딩용 파일을 넣는 단계입니다. 보통은 CLI가 자동으로 처리하고, 아래 명령은 자동 처리가 안 될 때만 확인합니다.

CLI 진행 방식

  1. 확인

    현재 작업 폴더, 설치 상태, GitHub 연결을 확인합니다.

  2. 질문

    한 번에 1-3개 질문으로 역할과 반복 업무를 이해합니다.

  3. 작성

    환경, 업무 지도, 미션 후보를 markdown 파일로 저장합니다.

  4. 갱신

    보드 데이터와 온보딩 상태를 갱신해 이 화면에 반영합니다.

  5. 다음

    확인한 내용과 다음 작은 행동을 알려주고 이어갑니다.
